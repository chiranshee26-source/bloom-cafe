# Photos go here

Put these photos in this folder **with exactly these names** (lowercase, `.jpg`).
Until a photo exists, the site shows a brown placeholder labelled with the file name.

## The place
| File name        | What it should show                                      | Shape     | Used on |
|------------------|----------------------------------------------------------|-----------|---------|
| `hero.jpg`       | Coffee cup from above on a light table (background)      | Landscape | Home background, top of every page |
| `cafe-1.jpg`     | Café interior, cosy seating area                         | Landscape | Home hero, Visit, Gallery |
| `cafe-2.jpg`     | Coffee counter                                           | Portrait  | Gallery |
| `cafe-3.jpg`     | Window seats or a sunny corner                           | Portrait  | Gallery |
| `storefront.jpg` | The café from outside (door, sign, street)               | Portrait  | Footer, Visit, Gallery |
| `flowers.jpg`    | Fresh flowers or plants on the counter                   | Portrait  | Home hero, Gallery |

Tips: free photos are available from https://unsplash.com and https://pexels.com.
Keep each file under ~400 KB (around 1600px wide is plenty) so the site loads fast.
You can shrink them for free at https://squoosh.app.
