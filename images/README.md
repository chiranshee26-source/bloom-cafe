# Photos go here

Put these 10 photos in this folder **with exactly these names** (lowercase, `.jpg`).
Until a photo exists, the site shows a brown placeholder labelled with the file name.

| File name      | What it should show                                    | Shape     |
|----------------|--------------------------------------------------------|-----------|
| `hero.jpg`     | Home background: coffee cup from above on a light table | Landscape |
| `cafe-1.jpg`   | Café interior, cosy seating area                        | Landscape |
| `cafe-2.jpg`   | Coffee counter / barista at work                        | Portrait  |
| `cafe-3.jpg`   | Window seats or a sunny corner                          | Portrait  |
| `coffee-1.jpg` | Latte / flat white with latte art                       | Portrait  |
| `coffee-2.jpg` | Iced coffee / cold brew in a glass                      | Portrait  |
| `coffee-3.jpg` | Coffee beans                               | Square    |
| `coffee-4.jpg` | Matcha latte                                            | Portrait  |
| `pastry-1.jpg` | Croissants                                              | Square    |
| `pastry-2.jpg` | Cinnamon rolls                                          | Landscape |

Tips: free photos are available from https://unsplash.com and https://pexels.com.
Keep each file under ~400 KB (around 1600px wide is plenty) so the site loads fast.
You can shrink them for free at https://squoosh.app.
